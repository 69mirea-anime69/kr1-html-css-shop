# Магазин «Точка»

Магазин предметов для рабочего стола.

## Страницы

- `index.html` — главная страница.
- `catalog.html` — каталог товаров.
- `product.html` — карточка лампы.
- `order.html` — форма заявки.
- `contacts.html` — контакты.

## Структура проекта

```text
kr1-html-css-shop/
├── index.html
├── catalog.html
├── product.html
├── order.html
├── contacts.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── images/
├── .gitignore
└── README.md
```

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках работы создаётся многостраничный сайт интернет-магазина. В нём есть главная страница, каталог, карточка товара, форма заявки и контакты. Используются семантическая разметка, внешний CSS-файл, навигация и базовое оформление страниц.

## Технологии

HTML, CSS (переменные, Flexbox, Grid и БЭМ), JavaScript для формы и окна заявки.
