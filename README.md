# Магазин «Точка»

Магазин предметов для рабочего стола.

## Страницы

- `index.html` — главная страница.
- `catalog.html` — каталог товаров.
- `product.html` — карточка лампы.
- `order.html` — форма заявки.
- `contacts.html` — контакты.

## Структура проекта

```text
kr1-html-css-shop/
├── index.html
├── catalog.html
├── product.html
├── order.html
├── contacts.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── images/
├── .gitignore
└── README.md
```

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта». На сайте есть главная страница, каталог, карточка товара, форма заявки и контакты.

## Самостоятельные доработки

- В каталоге есть категории и блок фильтров.
- На карточках товаров есть метки «Хит», «Новинка» и «Скидка».
- Меню одинаковое на всех страницах.

## Технологии

HTML, CSS и небольшой скрипт для формы заявки.

## Просмотр сайта

Откройте [GitHub Pages](https://69mirea-anime69.github.io/kr1-html-css-shop/) или запустите файл `index.html` в браузере.
