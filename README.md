# Магазин «Точка»

Контрольная работа №1 по теме «HTML и CSS: разработка многостраничного сайта».

## О проекте

Сайт магазина предметов для рабочего стола. В проекте пять страниц: главная, каталог, карточка товара, заявка и контакты.

## Страницы проекта

- index.html — главная страница и популярные товары.
- catalog.html — каталог.
- product.html — карточка лампы и характеристики.
- order.html — страница заявки.
- contacts.html — контакты.

## Использованные технологии

- HTML;
- CSS;
- JavaScript для модального окна и формы.

Данные формы проверяются в браузере и не отправляются на сервер.
