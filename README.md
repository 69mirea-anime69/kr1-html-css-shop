# Интернет-магазин «Точка»

Контрольная работа №1 по теме «HTML и CSS: разработка многостраничного сайта».

## О проекте

«Точка» — учебный макет интернет-магазина предметов для рабочего стола. В проекте есть главная страница, каталог, карточка товара, форма заявки и страница контактов.

## Страницы

- `index.html` — главная страница, преимущества, популярные товары и якорные ссылки.
- `catalog.html` — каталог карточек со статическими ссылками на категории.
- `product.html` — карточка лампы, таблица характеристик и CSS-модальное окно.
- `order.html` — форма заявки.
- `contacts.html` — контактная информация и форма обратной связи.

## Технологии

- HTML5 и семантическая разметка;
- CSS3, переменные, Flexbox и CSS Grid;
- базовые классы по методологии БЭМ;
- состояния `:hover` и `:focus-visible`;
- CSS-модальное окно на основе `:target`;
- локальные SVG-иллюстрации.

Сайт не использует CSS-фреймворки и JavaScript. Формы являются статическими учебными макетами, серверная обработка данных не подключена.

## Просмотр проекта

Откройте `index.html` в браузере. Все страницы связаны общей навигацией.
