# Магазин

Магазин предметов для рабочего стола. Фотографии взяты с [Unsplash](https://unsplash.com/license).

## Страницы

- `index.html` — главная страница.
- `catalog.html` — каталог товаров.
- `product.html` — карточка лампы.
- `order.html` — форма заявки.
- `contacts.html` — контакты.

## Технологии

HTML, CSS и JavaScript для формы заявки.
