# Магазин «Точка»

Контрольная работа №1 по теме «HTML и CSS: разработка многостраничного сайта».

## О проекте

Сайт магазина предметов для рабочего стола. В проекте пять страниц: главная, каталог, карточка товара, заявка и контакты.

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

Нужно сделать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг. В проекте должны быть:

- главная страница;
- каталог;
- карточка товара или услуги;
- страница оформления заявки;
- контакты;
- семантическая разметка и общая навигация;
- внешний CSS-файл с базовым оформлением.

## Страницы проекта

- `index.html` — главная страница, преимущества и популярные товары.
- `catalog.html` — каталог и ссылки на категории.
- `product.html` — товар, таблица характеристик и модальное окно.
- `order.html` — форма заявки.
- `contacts.html` — контакты и форма обратной связи.

## Использованные технологии

- HTML;
- CSS;
- JavaScript для формы заявки;
- Flexbox и CSS Grid;
- классы по методологии БЭМ;
- состояния `:hover` и `:focus-visible`.

Форма заявки проверяет заполнение полей в браузере. Данные на сервер не отправляются.

## CSS-архитектура

В файле `css/style.css` используются CSS-переменные для цветов, отступов и скруглений. Ссылки, кнопки и поля формы имеют состояния наведения и фокуса.

## Как открыть сайт

Откройте файл `index.html` в браузере. Ссылки в меню ведут на остальные страницы.
