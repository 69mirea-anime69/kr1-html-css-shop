# Магазин «Точка»

Магазин предметов для рабочего стола. Контрольная работа №1 по теме «HTML и CSS: разработка многостраничного сайта».

## Страницы

- `index.html` — главная страница, преимущества и популярные товары.
- `catalog.html` — каталог товаров и фильтры.
- `product.html` — лампа «Линия», таблица характеристик и окно заявки.
- `order.html` — форма заявки.
- `contacts.html` — контакты и форма обратной связи.

## Структура проекта

```text
kr1-html-css-shop/
├── index.html
├── catalog.html
├── product.html
├── order.html
├── contacts.html
├── css/style.css
├── js/main.js
├── images/
└── README.md
```

## Технологии

HTML, CSS и немного JavaScript для окна заявки. В стилях используются CSS-переменные, Flexbox, Grid и классы по БЭМ.
